KAITLYN BENEDETTO | KEYS BY KAIT WEBSITE
========================================
Upload the whole folder to your host, then open index.html.

CHANGE IMAGES: overwrite files in /images using the SAME file names. Placeholders say "REPLACE THIS IMAGE".
  images/kait/profile.jpg          About page + home + agent card
  images/kait/activity-*.jpg       Closed / open house flyers (replace with larger originals)
  images/listings/<id>-1..n.jpg    Listing photos (poolside-family-home and classic-white-farmhouse use real photos)
  images/banners/*.jpg             Page header photos
  images/home/*.jpg                Home page photos

CHANGE LISTINGS + CONTACT DETAILS: edit js/data.js (listings are SAMPLES).

EMAILS: searches, contact and tour forms are emailed to the address in js/data.js through FormSubmit.co.
  1) The site must be hosted online (forms do not send from a local file).
  2) The first submission sends an activation email to that inbox. Click "Activate" once.
